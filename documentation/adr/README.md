# Architecture Decision Records

One record per decision at the workspace, crate or project level. A choice
inside one component lives in that component's design document. The process
is in [`CONTRIBUTING.md` §3.2](../../CONTRIBUTING.md).
[Documentation index](../README.md) · [Workspace](../../README.md)

Numbers are assigned in order and never reused. A superseded record keeps its
row and names its replacement.
